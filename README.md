# Career Transition Analysis

> 不再用“我适合什么”做模糊判断，而是用经历证据回答：**我能转去哪、为什么、差在哪、下一步做什么。**

这是一个面向个人和职业咨询师的开源职业转型分析 Skill。它会读取个人说明书、简历、项目经历和目标方向，把零散经历转化为一份可验证、可比较、可执行的转行决策报告。

它不是职业性格测试，也不会只给出“你很有沟通能力”之类的泛泛结论。它更像一位研究型职业顾问：先建立事实底稿，再提取可迁移能力，结合目标岗位要求做匹配，最后给出差距、路径、求职资产和阶段性判断。

## 你最终会得到什么

一次完整分析会形成以下交付物：

1. **个人事实底稿**：学历、岗位、项目、成果、工具、行业经验与限制条件，并区分事实、推断和待确认信息。
2. **底层能力地图**：从经历中提取可迁移能力，不被原岗位名称限制。
3. **候选岗位组合**：通常给出 3–5 个可比较方向，而不是只押注一个岗位。
4. **岗位匹配矩阵**：逐项说明“为什么匹配、证据是什么、风险在哪里”。
5. **技能与认知 Gap**：区分硬技能、行业认知、业务场景、作品证据和求职表达问题。
6. **直接路径与桥接路径**：现在能投什么，以及如果跨度太大，先通过什么岗位或项目过渡。
7. **求职资产方案**：应该制作什么作品集、案例、简历 bullet 和面试故事。
8. **30/60/90 天行动计划**：把学习、作品、投递和反馈验证放进同一条路线。
9. **情景式 Prediction**：判断当前、补齐关键证据后、获得相关经历后三种情景下更可能进入什么岗位层级；不伪造录用概率。

```text
个人经历
   ↓
事实核验 → 能力提取 → 岗位匹配 → 差距排序 → 资产构建 → 市场验证
   ↑                                                    ↓
   └──────────────── 根据投递反馈持续更新 ──────────────┘
```

## 谁适合使用

### 特别适合

- 有 1–10 年工作经历，想跨行业、跨职能或进入新兴岗位的人。
- 做过很多事情，但不会把旧经历翻译成目标岗位语言的人。
- 同时对多个方向感兴趣，想比较机会成本和成功路径的人。
- 想从运营、市场、咨询、研究、项目管理等岗位转向 AI、产品、战略、增长、解决方案等方向的人。
- 职业咨询师、教练、招聘顾问，希望建立一套可复用分析流程的人。
- 不想先报课，而是想先判断“真正缺什么、哪些不必学”的人。

### 不适合直接使用

- 需要执照、强制学历或法定资质的职业，例如临床医生、律师等；这类转型必须先核验当地法规。
- 希望只凭性格或兴趣得到一个“命定职业”的人。
- 完全没有经历证据，又不愿通过项目、作品或实践补充证据的人。
- 希望得到“保证录用”或精确成功率的人。

## 它解决的不是一个问题，而是四个连续问题

| 阶段 | 用户常见困惑 | Skill 给出的答案 |
|---|---|---|
| Extraction | 我到底会什么？ | 从真实经历中提取能力、资源、偏好和约束 |
| Matching | 我能转什么？ | 用目标岗位要求对照候选方向，找出直接与桥接路径 |
| Gap | 我还缺什么？ | 按“影响 × 紧迫性 × 补齐成本”给差距排序 |
| Prediction | 我能走到哪一步？ | 用情景和证据成熟度判断近期、进阶和长期岗位可能性 |

## Step by step：完整流程

### Step 0：建立事实底稿

**你提供：** 个人说明书、简历、项目经历、作品、目标方向、时间与地点限制。

**Skill 会做：** 把材料拆成明确事实、合理推断和待确认项；发现冲突时先提问，不把猜测写成结论。

**你获得：** 一份可追溯的 Fact Ledger。后续每个判断都尽量能指回某段经历或外部岗位证据。

### Step 1：Extraction — 提取底层能力

分析不止看岗位名称，而是拆解四层信息：

- **任务层**：你持续做过什么。
- **能力层**：你用什么方法完成，例如研究、结构化、协调、销售、分析、交付。
- **证据层**：你做到什么程度，有没有结果、规模、复杂度或他人认可。
- **边界层**：你的兴趣、风险偏好、地点、薪资、时间和不可接受条件。

输出包括能力资产、可迁移技能、行业资源、动机偏好，以及尚未被证明的能力。

### Step 2：Matching — 匹配岗位与路径

你可以指定目标行业，也可以让 Skill 先生成候选方向。完整模式下，它应结合真实 JD 或公开招聘信息，比较：

- 核心任务是否相似；
- 必备能力是否已有证据；
- 行业壁垒是否能短期补齐；
- 现有身份能否被目标市场理解；
- 是否需要桥接岗位。

这里有三个决策 Gate：

1. **事实 Gate**：个人材料是否足以支持判断？
2. **市场 Gate**：目标岗位是否真实存在，需求是否稳定？
3. **可达性 Gate**：以当前证据，直接转入是否合理？

### Step 3：Gap — 找到最值得补的差距

Gap 不等于“列一堆课程”。每个差距都要回答四件事：

1. 它会不会直接阻碍面试或工作交付？
2. 是真的不会，还是会但没有证据？
3. 最快能用什么项目或作品证明？
4. 补齐之后，目标岗位是否会明显更近？

优先级通常为：**准入门槛 → 核心交付能力 → 作品证据 → 行业语言 → 加分项**。

### Step 4：Build — 把差距变成求职资产

Skill 会把学习建议进一步变成可展示的资产，例如：

- 一份目标行业研究或竞品分析；
- 一个从业务问题到 AI/产品方案的完整案例；
- 一组能体现过程和结果的作品集页面；
- 重新表述后的简历 bullet；
- 适用于面试的 STAR/CARE 故事；
- 用于验证市场反馈的小规模投递计划。

### Step 5：Prediction — 给出有条件的岗位判断

预测采用情景而非伪精确概率：

- **当前状态**：现在最有把握进入什么岗位，主要风险是什么。
- **短期补齐后**：完成关键作品、技能或行业验证后，岗位范围如何变化。
- **进阶状态**：获得一段相关经历后，可以进一步竞争什么岗位层级。

结论必须同时写清：判断依据、置信度、关键假设和可能推翻结论的新证据。

## 一个简化示例

**输入背景：** 4 年 B2B 客户运营经验，做过需求访谈、方案协调、续约和跨团队项目；想转 AI 产品，但没有产品经理头衔。

**普通建议：** 学产品经理课程，补 AI 知识，多投简历。

**这个 Skill 会进一步判断：**

- 已有资产：用户需求提取、复杂客户沟通、项目推进、商业结果意识。
- 证据不足：产品定义、数据指标、原型、技术边界判断。
- 直接路径：AI 客户成功、AI 解决方案、产品运营。
- 桥接路径：先进入靠近产品与客户的岗位，再用内部项目迁移到 AI 产品。
- 关键作品：选一个真实业务场景，完成用户研究、问题定义、方案流程、指标和 MVP 原型。
- 90 天验证：完成作品 → 访谈 5 位从业者 → 定向投递两类岗位 → 根据面试反馈更新 Gap。

真正的价值不是给出一个岗位名，而是把“看起来不相关的过去”重组为目标市场看得懂的证据链。

## 三种使用方式

### 1. 快速诊断

```text
请使用 career-transition-analysis 分析下面的背景。
先建立事实底稿并指出缺失信息，再提取我的底层能力，给出 3–5 个候选岗位。
暂时不要给长篇行动计划，先比较匹配度、主要风险和直接/桥接路径。

[粘贴个人背景]
```

### 2. 跑完整流程并生成报告

```text
请基于我提供的个人说明书运行 career-transition-analysis 全流程：
Fact Check → Extraction → Matching → Gap → Asset Building → Prediction。
请区分事实、推断和建议；结合真实岗位要求；最终输出一份完整职业转型报告，
包含岗位匹配矩阵、差距优先级、求职资产方案和 30/60/90 天计划。

我的目标行业/岗位是：[填写或写“请帮我探索”]
我的约束条件是：[地点、薪资、时间、风险偏好等]
[粘贴或附上材料]
```

### 3. 带着真实 JD 做定向分析

```text
请把我的背景与以下 3 个 JD 逐项对照。
不要只做关键词匹配，要区分：已经具备且有证据、可能具备但缺证据、明确缺失、无需补齐。
最后给出岗位排序、简历改写重点、面试风险和最小补齐方案。

[个人背景]
[JD 1]
[JD 2]
[JD 3]
```

## 为什么它不同于常见职业测试

| 常见做法 | Career Transition Analysis |
|---|---|
| 从性格标签推岗位 | 从真实经历和成果提取能力 |
| 只看“喜欢什么” | 同时看兴趣、证据、市场和约束 |
| 给一串可能职业 | 比较 3–5 个方向并解释取舍 |
| 把所有不足都列为 Gap | 区分能力缺失、证据缺失和表达缺失 |
| 推荐课程后结束 | 把学习转化为作品、简历和市场验证 |
| 给出确定性结论 | 明示假设、置信度和可推翻条件 |

## 使用原则

- **证据优先**：事实、推断、建议分开表达。
- **市场校验**：完整分析尽量使用真实 JD 和公开岗位信息。
- **角色组合**：默认比较多个方向，避免单点押注。
- **路径可执行**：建议必须能转化为项目、作品、投递或访谈动作。
- **能力与证据分离**：不会做与无法证明是两个不同问题。
- **保护隐私**：公开 Issue 或案例前，请删除姓名、电话、公司机密和其他个人敏感信息。

## 能力边界

- 这是决策支持工具，不替代招聘方判断，也不保证录用。
- 薪资、招聘需求和岗位定义会变化；涉及实时结论时应重新检索。
- 输入材料越具体，结论越可靠；信息不足时应先追问。
- Prediction 是基于证据和假设的情景判断，不是统计学录用概率。

## English summary

Career Transition Analysis is an evidence-based Agent Skill for career changers and career practitioners. It converts resumes, personal manuals, project histories, target roles, and real job requirements into a traceable transition plan: capability extraction, role matching, gap prioritization, bridge-role design, job-search assets, and scenario-based predictions. It is designed to produce actionable evidence—not personality-test labels or guaranteed outcomes.
