# 转行情报报告架构

完整报告不是固定堆砌九个章节，而是完成以下决策链。没有相应输入或用户不需要时，可以缩短模块。

## A 决策底座

1. **事实底稿**：背景、成果、目标、约束、冲突和确认状态。
2. **职业原型**：一句话说明候选人已经被什么证据验证，以及可以迁移到哪里。

## B 外部市场

3. **市场快照**：供需、招聘主体、薪资口径、趋势与风险。
4. **JD 基准**：高频职责、硬门槛、偏好项和岗位细分。
5. **行业认知包**：价值链、商业模式、主要玩家、关键议题和入门资料。

## C 人岗判断

6. **能力迁移图**：原经历证据 → 底层能力 → 目标岗位任务。
7. **岗位匹配矩阵**：首选、次选、桥梁和暂缓方向。
8. **Gap 清单**：能力缺口、行业缺口、证据缺口和现实约束，按 P0–P3 排序。
9. **招聘视角校准**：初筛优势、疑虑、需要验证的问题。避免模拟 HR 戏剧化独白。

## D 求职资产

10. **叙事主线**：为什么转、凭什么转、为什么是现在。
11. **经历重构**：保留事实，用目标岗位可识别的语言表达，不虚构指标或职责。
12. **面试证据库**：高频问题、回答框架和对应真实案例。
13. **Portfolio**：主题、目标读者、核心问题、数据源、产出格式和完成标准。

## E 执行与预测

14. **目标公司 Mapping**：主攻、主要战场、保底或桥梁、探索。
15. **行动路线**：30 / 60 / 90 天任务、交付物、验收标准和投入时间。
16. **情景预测**：现在可投、短期可达、进阶可达；乐观、基准和保守情景。
17. **切换条件**：依据面试率、反馈类型和时间预算决定继续、调整或启用桥梁路径。

## 三个阶段闸门

- **闸门 1 事实确认**：关键日期、成果和目标未确认，不进入评分。
- **闸门 2 方向确认**：用户从候选方向中选定 1–2 个，才深挖公司和作品集。
- **闸门 3 市场验证**：用真实投递和面试反馈更新预测，不把初始报告当最终答案。

## 最终自检

- 每个强结论是否有候选人证据或市场来源？
- 每个 Gap 是否对应具体补齐动作和可观察产物？
- 每个行动是否服务目标岗位，而不是泛化学习？
- 是否把“缺少证据”误写成“缺少能力”？
- 是否存在精确但无依据的成功率、薪资或时间承诺？
