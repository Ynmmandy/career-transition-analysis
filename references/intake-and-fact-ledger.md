# 输入与事实底稿

## 最小输入

分析至少需要以下四类信息；缺失时可以先做阶段性版本，但必须标注未知项：

1. **经历**：起止年月、岗位、公司或行业、职责、成果。
2. **证据**：数字、项目、作品、评价、合同、客户或交付结果。
3. **目标**：感兴趣行业、岗位、城市、期望层级和薪资。
4. **约束**：转型期限、可投入时间、降薪容忍度、地域与不可接受项。

可选输入包括简历、个人说明书、目标 JD、作品集、面试反馈和投递数据。

## 事实底稿字段

| 字段 | 记录要求 |
|---|---|
| 教育背景 | 学校、专业、学历、起止年月、授课语言或可信证书 |
| 工作经历 | 公司、岗位、行业、起止年月、实际职责 |
| 成果证据 | 原始表述、数字口径、候选人承担的角色、可否验证 |
| 技能证据 | 使用场景、频率、产出和熟练度，不只列工具名 |
| 转型目标 | 行业、岗位族、城市、层级、薪资和优先级 |
| 现实约束 | 时间、预算、家庭、身份、风险偏好和机会成本 |
| 来源 | 用户自述、简历、作品、JD 或公开资料 |
| 状态 | 已确认、合理推断、存在冲突、待确认 |

## 强制校验

- 根据起止年月计算任职时长；“至今”使用当前日期，不能把年份差误读成月份差。
- 检查同一成果在不同材料中的金额、人数、比例和角色是否一致。
- 区分“主导、参与、支持”和“团队完成”，不得自动升级责任范围。
- 区分原始业务指标与目标行业术语；只有定义一致时才能换名。
- 发现会影响岗位层级或路径选择的冲突时，暂停评分并询问用户。

## 证据强度

- **强**：有量化结果、明确角色、具体场景或可展示产物。
- **中**：有具体行为，但结果、角色边界或验证材料不足。
- **弱**：只有自我评价、技能标签、兴趣或未经执行的计划。

先锁定事实，再做职业解释。历史报告、旧评分或他人评价只能作为参考输入，不能覆盖最新事实。
